# 원작 대조 대장 — 플래티넘에 있는 것 / 우리에게 있는 것

이 문서는 **결손 목록**이다. "언젠가 하자"가 아니라 *무엇이 없고, 그것이
원작 어디에 있고, 무엇을 재면 되는가*를 적는다. 다 하면 이 문서는 빈다.

정본은 디컴프(`pret/pokeplatinum`)다. 짐작으로 적은 줄은 없다 — 각 줄의
"근거" 칸이 원작 파일이나 우리가 잰 수를 가리킨다.

- 진행 상태와 구현 노트는 [PLAN.md](PLAN.md), 자료 추출은 [DATA.md](DATA.md)가
  정본이다. 여기는 **차이만** 적는다.
- ✅ 됨 · ◐ 반쯤 · ✖ 없음 · ⊘ 범위 밖 (§9에 이유)

## 9. 범위 밖 — 이유를 적는다

안 하는 것도 결정이므로 적어 둔다. "못 한다"가 아니라 **"이 판에서는 뜻이
없다"**는 것이다.

| | 왜 |
|---|---|
| 통신 대전·교환 · 유니온룸 · GTS · Wi-Fi 광장 | 상대가 있어야 성립한다. 서버를 세우는 일이고 게임 이식이 아니다. 스크립트 자리 158 |
| 미스터리기프트(배포) | 위와 같다. 배포 서버가 닫힌 지 오래다 |
| 배틀타워·프론티어 | 통신 상대·기록 교환이 절반이고, 나머지 절반(연속 대전)은 §2 위에 얹으면 되므로 **§2가 끝난 뒤에 다시 본다** |
| 콘테스트 통신 대전 | 로컬 콘테스트(§7.1)는 범위 안이다. 통신 쪽만 밖 |
| 지하통로 통신 | 로컬 발굴·비밀기지는 범위 안 |
| NDS 터치 자판 | 입력 장치가 다르다. 키보드 자판으로 대신한다 |
| 모바일 | 노트북 이상이 목표다 (PLAN §1.2) |
