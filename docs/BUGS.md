# 원작 버그 대장 — 옮기지 않는 것

[PARITY.md](PARITY.md)가 *없는 것*을 적는다면 이 문서는 **있는데 옮기면 안 되는
것**을 적는다. 플래티넘에는 버그가 있고, "원작 그대로"를 곧이곧대로 밀면 그
버그까지 따라 만들게 된다.

두 갈래를 겹쳐서 세었다.

- **디컴프가 스스로 표시한 자리** — `pret/pokeplatinum`의 `// BUG:` 주석
  48자리(23개 파일). 코드 줄을 가리키므로 제일 정확하다.
- **밖에서 정리된 목록** — Bulbapedia의 4세대 글리치 세 문서(전체·배틀·필드).
  플레이어가 실제로 겪은 증상 쪽이라, 디컴프가 표시 안 한 것도 잡힌다.

## 0. 셋을 가른다

| | 뜻 | 어떻게 하는가 |
|---|---|---|
| **버그** | 원작 코드가 **제 의도와 다르게** 돈다 | 재현하지 않는다. 의도대로 고쳐 옮긴다 |
| **사양** | 이상해 보여도 **그렇게 만든** 규칙 | 그대로 옮긴다 (§3) |
| **밖** | 통신·저장 손상·2D 하드웨어처럼 우리에게 **자리가 없다** | 옮길 것이 없다 (§4) |

가르는 기준은 취향이 아니다. 디컴프가 `// BUG:`라고 적었거나, 버려진 식·
덮어쓰인 변수·오타난 상수처럼 **코드가 자기 모순인 자리**만 버그로 친다. "4세대가
5세대보다 불친절하다"는 것은 버그가 아니다.

## 1. 우리 코드에 닿았고, 고쳐서 옮긴 것

| | 원작이 하는 일 | 원작 자리 | 우리 |
|---|---|---|---|
| 1.1 **비전머신5 팔레트** | 디폿(비행)이 가방에서 **물빛**으로 뜬다 | `res/items/data/hm05.json`의 `icon.palette`가 `tm_water` | `tm_flying`으로 고친다. 눈으로 고르지 않았다 — 기술머신·비전머신 100개를 **기술 타입별로 묶어** 팔레트가 갈리는 묶음을 셌고, 17개 타입 중 **어긋나는 것이 정확히 HM05 하나**다. 생성기가 이 검사를 매번 돌린다 |
| 1.2 **끈끈이·흡반의 낚시 보정** | 두 특성이 낚시 출현률을 **2배로 못 만든다** | `wild_encounters.c:1333` — `newEncRate * 2;` 가 버려진 식이다(`*=`가 아니다). 디컴프가 `// BUG:`로 표시 | 2배로 만든다. 두 특성이 낚시에 붙는 유일한 효과라, 안 고치면 그 자리가 통째로 죽는다 |
| 1.3 **자력·정전기가 물에서** | 파도타기·낚시에서 두 특성이 **안 돈다** | `wild_encounters.c:1111·1122` — 자력 판정 결과를 정전기 판정이 **덮어쓴다**(`if (!forcedSlot)`가 빠졌다). 풀숲 쪽에는 있다 | 풀숲과 같은 차례로 돌린다 — 강철이면 자력, 아니면 전기면 정전기 |
| 1.4 **개체값 유전 중복** | 물려받을 능력치 셋을 뽑을 때 **같은 칸을 두 번 뽑을 수 있다** | `RemoveIVIndexFromList(availableIVs, i)` — 뽑은 칸이 아니라 **루프 변수**를 지운다 | 뽑은 칸을 지운다. 셋이 늘 서로 다르다 |

⚠️ **1.4는 되돌린 것이다.** 처음에는 "원작을 그대로"를 이유로 이 버그까지 옮겼고
시험도 그 성질을 재고 있었다. 자기 모순인 코드(지우려는 대상과 지우는 대상이
다르다)라 §0 기준으로 버그가 맞다.

## 3. 버그가 아니다 — 그대로 옮긴 것

⚠️ **여기 있는 것을 "고치면" 다른 게임이 된다.** 4세대가 그렇게 만든 규칙이다.

| | 규칙 | 왜 사양인가 |
|---|---|---|
| 3.1 **변함없는돌 50%** | 성격이 절반만 유전된다 | 5세대에서 100%로 **바뀐** 것이지, 4세대가 틀린 것이 아니다. 코드에 모순이 없다 |
| 3.2 **친밀도 칸이 알 주기를 겸한다** | 알일 때 같은 바이트가 남은 부화 걸음이다 | 자료 구조를 아껴 쓴 것이다. 부화하면 120으로 덮인다 |
| 3.3 **파도타기 조우가 여섯 칸에서만** | 탈 수 있는 물 16종 중 6종에만 조우가 붙는다 | 폭포와 물 위 다리에 조우를 안 붙인 것은 **의도**다. 거동마다 표식이 따로 있다 |
| 3.4 **평평한 40% 관문** | 출현률을 보기 전에 걸음의 60%가 떨어진다 | 출현률표의 값이 걸음당 확률이 **아니게** 설계된 것이다 |
| 3.5 **낚시 창이 대단한 낚싯대에서 제일 짧다** | 45 → 30 → 15프레임 | 좋은 것을 낚으려면 더 빨라야 한다는 것이 이 표의 뜻이다 |
| 3.6 **글 잠금 검사가 죽어 있다** | 낚시 글의 `counter < 16`이 한 번도 안 걸린다 | 부르는 셋이 전부 `counter = 16`으로 세워 놓고 온다. **결과가 안 바뀌는** 죽은 코드라 옮길 것도 고칠 것도 없다 |
| 3.7 **부화 검사가 256걸음에 한 번** | 걸음마다 굴리지 않는다 | 걸음마다 굴리면 몇 걸음 만에 깬다 |
| 3.8 **알은 부화 특성 검사에서 빠진다** | 마그마의무장·불꽃몸을 셀 때 알을 건너뛴다 | 알이 알을 데우지 않는다는 뜻이다 |

## 4. 우리에게 자리가 없는 것

옮길 코드가 없다. 만들 계획도 없다 — 이유는 [PARITY](PARITY.md) §9와 같다.

- **통신 전부** — GTS 복제·모습 바뀜·교환 진화 우회·교환 도중 전원 끄기·
  DNS 미스터리기프트·Wi-Fi 플라자 겹침·배틀레볼루션 셋. 통신이 없다.
- **저장 손상 계통** — 손상된 파일에서 교환해 복제하기. 우리 저장은 브라우저
  저장소의 한 판이고 부분 손상이라는 상태가 없다.
- **팔파크 이름 인코딩** — 서양판이 `0` 앞 글자에 일본어 표를 쓴다. 우리는
  글자를 사용자 롬에서 읽는다.
- **포켓워커 복제** — 기기가 없다.
- **2D 하드웨어 계통** — 배경 타일이 휘는 그래픽 깨짐, 기술 연출마다 스프라이트가
  몇 픽셀씩 밀리는 것(`battle_anim` 아홉 자리), `bg_window.c:2651`의 무한 루프,
  타이틀 화면 기라티나 흔들림 각도. 전부 NDS의 2D 엔진·G3D 파이프라인 자리라
  R3F에는 대응하는 코드가 없다.
- **여섯 마리 프레임 저하** — 하드웨어 성능 문제다.
- **트위킹·보이드** — 맵 행렬을 스트리밍하는 구조를 파고드는 것이다. 우리는
  맵을 통째로 싣는다.
- **글자 자체의 오타** — 승리의길 검은띠 에디의 줄바꿈, 「Member's Card」.
  글은 한 자도 우리 것이 아니라 사용자 롬에서 나온다([COPYRIGHT](COPYRIGHT.md)
  §2). 고치려면 원문을 우리가 들고 있어야 하므로 손대지 않는다.
