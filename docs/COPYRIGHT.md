# 저작권과 배포

원본 에셋을 쓰는 팬 프로젝트로서 **무엇을 판단했고, 그 판단이 배포에 무엇을
요구하는가**. 기술적 배포 설계(호스팅 후보 비교·CORS·Service Worker·캐싱)는
PLAN.md §4.6에 있고, 여기서는 저작권이 이유인 것만 다룬다.

---

## 1. 결정

**비영리 팬 프로젝트로서 원본 에셋을 사용한다.** 프로젝트 오너 판단이다.
PLAN.md §4.1(즉시 플레이 배포) · §4.3(모델 립 활용) · §4.5(원본 SSEQ)가 그 결과다.

**배포는 코드 공개 저장소 + 원본 유래 데이터 CDN. 제목 · 홍보 · 검색 노출은
건드리지 않는다.**

수익화하지 않는다는 전제가 위 판단에 붙어 있다. 광고 · 후원 · 유료화를 붙이면
판단의 근거가 달라지므로, 도입을 검토할 일이 생기면 이 문서부터 다시 읽는다.

---

## 2. 위험은 두 축이고, 한 축만 다룬다

| 축 | 대상 | 자세 |
|---|---|---|
| **저작권** | 스프라이트 · 모델 · 대사 · SSEQ · 수치 | **저장소와 히스토리에서 뺀다.** 원본 바이트는 CDN에만 둔다 (§5·§6) |
| **상표** | "Pokémon" 제목 · 도메인 | **다루지 않는다.** 팬게임이 제목에 원작명을 붙이는 건 관례다. 이름을 바꿔도 저작권 축은 그대로 남으므로, 얻는 것보다 정체성 손실이 크다 |

---

## 3. 비수익화는 방패가 아니다

계산을 정확히 해 둔다. 내려간 팬게임 대부분이 무료였다 — Uranium · Prism ·
Brick Bronze 전부 무료 배포였다. 닌텐도의 팬게임 DMCA는 상습적이고,
Uranium('16) · Essentials('18) · Game Jolt 550+건('21) · Relic Castle('24)로 이어진다.

트리거는 셋이다: **인지도 급상승 · 완성형 · 수익화.** 수익화는 그중 하나일 뿐이고
주된 방아쇠는 앞의 둘이다. 면책 문구의 효과는 0이다.

그러니 비수익화는 *안전해지는 수단*이 아니라 **표적 우선순위를 낮추는 수단**으로만
계산한다. 수익화 금지는 법적 방어가 아니라 **프로젝트 생존 전략**이다.

이 판단의 귀결이 §6이다 — 안전해지려 하지 말고, 채널이 죽어도 프로젝트가 안 죽게 만든다.

## 4. 에셋 정책

### 저작권과 무관하게 유지되는 제약

정책이 바뀌어도 아래 셋은 그대로다. 이유가 저작권이 아니기 때문이다.

| 항목 | 사유 |
|---|---|
| 에셋을 git에 커밋하지 않음 | **git이 바이너리를 못 다룬다.** 히스토리 영구 오염, clone 시간 폭증. CDN + 매니페스트 (PLAN.md §4.1) |
| DS 맵 지오메트리를 최종 렌더에 미사용 | **품질.** 웹 해상도에서 DS 폴리곤은 견딜 수 없다. 블록아웃 레퍼런스로는 적극 활용 (PLAN.md §4.2) |
| 포켓몬 모델 어댑터 인터페이스 | **정규화 필요.** 종마다 스케일 · 축 · 클립 세트가 다르다 (PLAN.md §4.3) |

### 실무 메모

- 백업을 로컬 + 별도 원격 두 곳에 둔다. 호스팅 플랫폼 의존을 낮추는 건 어떤
  프로젝트든 기본이다
- README에 비공식 · 비영리 및 상표권 귀속 표기 — 관례이고 비용이 0이다
- 코드(엔진 · 파이프라인 · 툴)와 에셋을 저장소 수준에서 분리해두면, 나중에 어떤
  이유로든 에셋 정책을 바꿔야 할 때 코드는 그대로 살아남는다. PLAN.md §15 구조가
  이미 그렇게 되어 있다

## 5. 저장소 — git 히스토리

**작업 트리에서는 다 뺐다.** `.gitignore`가 `public/models/`와 `public/data/`를
폴더째 막고, 추적 중이던 **2,559 파일 / 11.0MB**를 `git rm -r --cached`로 놓았다.
지금 추적 중인 롬 유래 파일은 0개다.

**히스토리에는 아직 같은 경로의 블롭이 2,748개 남아 있다** — 그건 아래 3번이다.

뺀 것이 무엇이었는지는 남겨 둔다. 무엇을 다시 빼야 할지 판단할 때 쓴다:

| 경로 | 크기 | 내용 |
|---|---|---|
| `public/data/matrices/` | 3,444KB | 신오 전체의 청크 배치 |
| `public/data/dialogue/{ko,en,ja}/` | 3,419KB | **게임 전체 대본 3개 언어** |
| `public/data/pokemon/` | 951KB | 포켓몬 스프라이트 986장 (앞 · 뒤) |
| `events.json` · `scripts.bin` · `bdhc.bin` | 1,159KB | 배치 · 스크립트 바이트코드 · 높이 |
| `species.json` · `encounters.json` · `trainers.json` · `items.json` · `names/` | 1,200KB | 이름 · 설명문 · 수치 |
| `public/data/npc/` · `starter/` | 356KB | NPC 스프라이트 156장 · 고르는 장면 모델 |
| `itemIcons.png` · `pokeIcons.png` · `boxWallpapers.png` · `signposts.png` | 아틀라스 |

⚠️ **제일 큰 둘이 §4가 말하는 "알아보기 쉬운 저작물"과 다르다.** 눈에 걸리는 것은
대사와 스프라이트인데, 부피의 62%는 `matrices/`와 `dialogue/`다. 조치는 안 바뀌지만
(폴더째 뺐다) **매니페스트가 첫날 무엇을 날라야 하는지**가 달라진다.

추적 밖이던 것까지 합치면 실제 부피는 훨씬 크다 — 전부 **6,558개 · 99.9MB**이고,
그중 NPC 모델 38.1MB · 청크 28.4MB · 소리 7.5MB가 위 표에 아예 없었다.

`public/assets/`는 **대상이 아니다** — 파비콘 · 아이콘 · 인트로 그림은 자체 제작이다.

⚠️ **목차만 남기는 예외는 두지 않았다.** 두려고 로더가 첫 왕복에 읽는 것을 재 봤더니
16개 2.6MB였는데 그 안에 `matrices/0.bin`(1.8MB, 신오 전체 배치)과
`encounters.json`(254KB)이 있었다 — 빼려던 바로 그것이라 예외가 성립하지 않는다.
목차 노릇은 `assets-manifest.json`이 대신한다: 경로 · 크기 · sha256 앞 8바이트를
6,558줄에 담은 325KB짜리로, **롬 바이트가 아니라 롬 바이트의 목차**다 (DATA.md §3.3).

**아직 `git remote`가 없다 — 커밋 전부 로컬이고, 지금이 비용 0인 유일한 시점이다.**
push 후에는 히스토리 재작성이 모든 클론을 무효화하고, GitHub는 DMCA 통지를 공개
아카이브(`github/dmca`)에 영구 게시한다.

### ⚠️ 자료가 없을 때 시험이 조용히 초록이 되지 않게 한다

**시험 파일 98개 중 51개가 자료 유무를 보고 건너뛴다.** 자료가 gitignore이니 그
자체는 맞는 설계인데, 모으기 전에는 없을 때 무슨 일이 나는지가 **파일마다
달랐다.** 자료를 치우고 재 본 값:

| | |
|---|---|
| 그 자리에서 터진다 | **41** |
| **조용히 초록으로 끝난다** | **10** |

⚠️ 41개가 시끄러웠던 것도 설계가 아니라 **우연이다.** vitest는 건너뛰는 묶음도
몸통을 수집하므로, 몸통 첫머리에서 파일을 읽는 시험은 건너뛰기와 상관없이
`ENOENT`로 터진다. 자료를 `it` 안에서만 읽는 열 개는 안 터진다 — 실측:
`trainers.test.ts`의 자료를 치우면 **9 skipped · 종료 코드 0**이었다.

이 프로젝트는 조용한 통과에 이미 한 번 당했다 — `shell.test.ts`가 색을 손으로
만들어 넘기는 바람에 소품 189종이 뚫린 채로 통과하고 있었다(DATA.md §2.2).

그래서 건너뛰기를 한 군데(`src/data/romData.testkit.ts`)로 모으고, `pnpm check`에서는
없을 때 건너뛰는 대신 **세운다**(`PT_REQUIRE_DATA=1`). 손으로 `describe.skip`을 다시
적는 것은 lint가 막는다 — 안 막으면 다음 시험 하나 붙일 때 도로 는다.

### 순서

| | | 되돌릴 수 있나 | |
|---|---|---|---|
| 0 | 자료가 없으면 시험이 **선다** — 게이트 한 군데 + lint | 덧셈뿐 | ✅ |

2번의 ⚠️ **버킷이 없으면 못 당긴다는 닭과 달걀**은 두 갈래로 풀었다 — 주소가 있으면
받고, 없으면 그룹별로 `pnpm extract:*`를 찍고 선다. R2를 세우는 일이 3·4번을 막지
않는다. 두 갈래 다 실제로 돌려 봤다(로컬 서버로 세운 가짜 버킷에서 3/3 바이트 일치).

3번의 ⚠️ **예외 목록은 손으로 적지 않았다** — 재 봤더니 예외가 성립하지 않았다(위).

4번 전에는 `.git`을 통째로 복사해 둔다. 히스토리 블롭 2,748개가 대상이다.

## 6. 배포 — 이관 가능하게

호스팅 구성은 PLAN.md §4.6(Cloudflare Pages + R2)을 그대로 쓴다. 여기서 더하는 것은
하나뿐이다: **배포 채널은 언젠가 사라진다는 전제로 만든다.** 채널이 죽는 것과
프로젝트가 죽는 것을 분리하는 게 목적이다.

- **에셋 CDN 주소를 코드에 박지 않는다.** 에셋 경로를 만드는 곳은
  `src/data/assetBase.ts` 하나다 — `dataUrl()` · `modelUrl()`, 그리고 앱 셸로
  되돌아가는 데만 쓰는 `APP_ROOT`. 뿌리는 `VITE_ASSET_BASE`가 있으면 그쪽, 없으면
  앱 셸과 같은 자리라 지금 배포는 설정 없이 그대로 돈다.

  ⚠️ **20군데였다.** 전부 `import.meta.env.BASE_URL`을 직접 읽고 있었는데, 앱 셸을
  Pages · 에셋을 R2에 두는 순간 오리진이 갈려 전부 404가 된다. **오늘은 틀려도 안
  깨지는 것**이 문제였다 — 두 오리진이 같아서 새로 쓰는 자리마다 조용히 늘었다.

  ⚠️ **그래서 lint로 못을 박았다.** 그 모듈 밖에서 `import.meta.env.BASE_URL`을
  금지한다(`eslint.config.js`의 `BASE_URL_FORBIDDEN`). 이 리포는 "UI에서 three 금지"에
  이미 같은 장치를 쓴다. 다만 플랫 설정은 같은 규칙 이름을 두 블록에 쓰면 뒤가 앞을
  통째로 덮으므로, 시험 파일 블록은 조각을 **둘 다** 합쳐서 쓴다 — 그리고 규칙이
  죽어도 `assetBase.test.ts`가 "src에서 그걸 읽는 파일은 하나"를 따로 센다
- R2 미러 버킷 + 로컬 백업. `raw/`(11GB)를 오프라인에 보관해 두면 에셋은 언제든
  재생성된다 — 파이프라인이 있는 한 에셋 소실은 복구 가능한 사고다
- 코드 저장소와 에셋 저장소를 분리한다. 에셋이 내려가도 코드는 남는다 (§4 실무 메모)
- itch.io는 총 500MB 제한으로 본배포엔 못 쓰지만(PLAN.md §4.6), 채널이 하나 사라졌을
  때의 **대피소**로는 의미가 있다

| **수익화 0** | 광고 · 후원 · Ko-fi · Patreon 전부. 후원 링크 하나가 "팬 프로젝트"를 "상업적 이용"으로 재분류시킨다 |

## 8. 명시적 비채택

| 항목 | 사유 |
|---|---|
| **제목 · 도메인에서 "Pokémon" 제거** | 오너 결정. 팬게임 관례상 일반적이고, 이름을 감춰도 저작권 축은 그대로다 (§2) |
| **검색 비노출 (noindex · robots.txt)** | 오너 결정. 홍보 수위는 오너가 판단한다 |
| **면책조항으로 방어** | 효과 0 (§3). 표기는 관례로만 유지한다 (§7) |
| **BYOR — 사용자가 자기 ROM을 넣고 브라우저에서 추출** | 호스팅의 저작물이 0이 되는 가장 안전한 길이고 `tools/extract/*`가 순수 JS라 포팅도 현실적이지만, PLAN.md §4.1이 "최종 사용자는 ROM이 필요 없다"를 이미 결정했다. 게다가 BDSP 유래 모델(PLAN.md §4.3)은 Switch 파일이라 사용자 추출이 비현실적이라 절반만 덮인다. **에셋 정책을 바꿔야 할 상황이 오면 1순위 대안이다** |
