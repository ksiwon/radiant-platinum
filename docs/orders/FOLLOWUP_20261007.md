## 3. 알고 넘긴 작은 것

- **우박 날씨 `et002_hail01`이 안 보인다** — `/fxlab`(t=4s · zoom 0.5)에서 입자 17개가 사는데 화면에 아무것도 없다. 배틀에서도 지속 우박이 안 읽혔다.
  공개판은 우박만 지은 연출로 세웠다(`BattleAtmosphere` `Weather`). 방출 자리(높이 · 카메라 붙음) · 크기 · 재질을 비 · 모래바람과 대조한다.
  햇살 `et004_sunny01`은 위쪽 빛 띠만 보인다 — 원작이 그 모양인지 BDSP 화면과 대조한다.
- **WebGL 경고 22건** — journey `c82a4d5` 판 ⑯이 오류 0 · 경고 22로 떨어졌다: `texSubImage2D: The source data has been detached` · `glDrawElements: Must have element array buffer bound`(`WebGLBackend`). 화면(⑮) · 이어하기는 섰다.
  시점을 모른다 — `journey.mjs`가 `noise`에 `at` · `when`을 모으고도 안 찍는다. 먼저 경고마다 그때의 맵 · 씬을 찍게 하고 잰다.
  후보: `src/scene/disposeTree.ts`가 떼는 지역의 `ImageBitmap`을 `close()`한다 — 다른 쪽이 같은 그림을 쥐고 있었으면 닫힌 것을 다시 올린다. 낮게 `BdspEffect.tsx`의 형상 풀.
  같은 판에서 구간마다 「캔버스가 2개다」(`canvasShot.mjs`)로 캔버스를 못 뗐다 — 둘째 캔버스의 정체도 같이 본다.
- 능력 오름 `es008_up` 빛기둥이 칼춤 근접 카메라에서 화면 절반을 덮는다 — 원작 모양이 맞는지 BDSP 화면과 크기 대조.

- 방음 같은 특성 막기(`block` 사건)는 기술 연출이 아직 돈다 — 원작은 빗나감 갈래인지 확인 후 `blockedAfter`에 넣는다.
- 일시정지 동안 시퀀스가 돌던 중이면 체력판이 숨은 채로 있다(다시 진행하면 돌아온다).
- 빗나간 기술 뒤에 `from` 없는 능력 변화가 오면 `lastEffect.moveSeq`가 앞 기술 번호를 본다 — 정상 흐름에는 없다.
- `tools/e2e/drive.mjs`의 `pickMove` · `pickFighter`는 강습을 모르고 진짜 클릭을 한다 — 이제 삼켜지므로 무해하지만, 강습 동안은 안 누르게(`useBattleStore.getState().ally`) 고치면 로그가 깨끗하다.
