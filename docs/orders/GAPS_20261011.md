# 빈자리 전부 메우기 (2026-10-11 · v1.2.2 `0f8f7ae` 뒤)

사용자 지시: 범위 밖으로 뺀 것이 아니면 **다 만든다.** 근사 · 멈춘 그림 · 빠진 장면을 남기지 않는다. **전부 3D로 만든다** — 판때기 · 평면 그림 · 우리 도형으로 메우지 않는다(크레딧 장면 · 이펙트 · 사람 · 물건 모두).

범위 밖(이 문서에서 다루지 않는다): 프런티어 타워 · 스테이지 · 캐슬 · 룰렛, 콘테스트, 지하통로, 통신, 모바일, 대사 한 자씩 찍기.
사용자 결정으로 원작과 다른 것(그대로 둔다): 배틀 무대에 사람이 안 선다 · 볼 0.3m · 등판 글이 누를 때까지 선다 · 대각선 이동.

출처: 문서 훑기(`PARITY` · `PLAN` · `REPAIR` · `DATA`), 지시서 미결 훑기(`docs/orders`), 코드 훑기(대체 경로 · 자리표시자). 셋 다 읽기만 한 조사라 줄마다 **착수할 때 다시 잰다.**

**성능 규칙** (사용자 지시 — 렉을 줄여 부드럽게). 새로 움직이는 것은 다음을 지킨다:
- 움직임은 GPU에서 — UV 스크롤 · 그림 교체 · 흔들림은 셰이더 균일값 하나(시간)로 돈다. 재질 · 메시마다 CPU 갱신을 하지 않는다. 같은 값의 재질은 셰이더를 같이 쓴다(파이프라인 수를 늘리지 않는다).
- 새 재질 · 모델 · 파티클은 비동기로 굽는다(`ALWAYS_ASYNC` · `addWhenWarm`) — 그려지는 프레임에 동기 컴파일로 멎지 않게.
- 화면 밖 · 먼 것은 안 민다(믹서 · 파티클 · 회전). 먼 사람은 동작 갱신을 띄엄띄엄(`FAR_EVERY`처럼). 파티클은 통에서 돌려 쓴다.
- 사람 수 상한을 넘기는 일은 수가 아니라 비용을 묶는다 — 먼 사람은 가벼운 3D(뼈 · 정점을 줄인 판, 같은 갈래는 인스턴싱).
- 갈래마다 합치기 전에 잰다: 프레임 시간(평균 · 최악) · 그리기 호출 · 파이프라인 수 · 동기 컴파일 건수, 무거운 맵(로비 · 사람 많은 거리 · 풍차 area003 · 폭포 area005)에서 전후를 비교한다.
