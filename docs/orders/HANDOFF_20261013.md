## 0. 먼저 확인한다

- 압축 파일 `radiant-platinum-untracked-20261013.tar`를 리포 뿌리에서 푼 뒤 다음이 있는가:

  - `public/data/` · `public/models/` (1.8GB) — 구운 자료. 있으면 다시 안 굽는다
  - `.audit/parts/cell-1~7.{rpsave,json,memory.json}` — 연쇄를 칸 8부터 잇는 데 쓴다
  - `.audit/morning-report-20261013.html` — 그날 보고서. 이어서 갱신한다
- 기억 폴더 `_claude-memory/`는 사용자가 `~/.claude/projects/<리포 경로를 -로 이은 이름>/memory/`로 옮긴다
  (예: `/Users/me/code/radiant-platinum` → `-Users-me-code-radiant-platinum`). 규칙이 전부 거기 있다 —
  **보고는 한국어 · `rm -rf` · `git reset --hard` · `git stash` 금지 · 남의 node 프로세스는 안 죽인다 ·
  판 도중 src 금지 · 보고서는 `.audit/`의 HTML · 연쇄는 찾고 나서 한 번에.**
- 하나라도 없으면 멈추고 사용자에게 말한다. 없는 것을 지어 채우지 않는다.

## 1. mac에서 다른 점 (아직 mac에서 안 돌려 봤다 — 처음 돌 때 잰다)

- `package.json`의 추출 스크립트 17개가 `py -3.13`(Windows 실행기)을 부른다. 추출은 이번 일에 필요 없다(자료를 옮겼다).
  다시 구워야 하면 `python3.13`으로 돌린다.
- `tools/gpuFlags.mjs`: Windows는 ANGLE · `use_dxc`를 끄는 플래그를 쓴다(`process.platform === 'win32'`).
  mac은 Metal 경로다. 헤드리스 WebGPU가 뜨는지 첫 판에서 본다(`document.documentElement.dataset.renderer`).
- `.audit/part-watch2.sh`(정체 감시)는 Windows `powershell`로 프로세스를 찾는다 — mac에서는 `pgrep -f part.mjs`로 바꿔 쓴다.
- 설치: Node 22 · pnpm · `pnpm install` · `npx playwright install chromium`.
- 줄바꿈: Windows 쪽 Git이 CRLF 경고를 냈다. mac은 LF 그대로 두면 된다.

## 3. 다음 할 일 (차례대로)

1. **연쇄를 잇는다** — `pnpm parts --from=8 --no-video 2>&1 | tee .audit/parts-chain-<sha>-from8.log`
   칸마다 끝나면 한국어로 보고. 정체 감시를 같이 건다:
   로그가 10분 조용하거나 마지막 도착 뒤 「같은 칸에서 3분째다」가 세 번이면 그 판을 끊고 고친다.
   하네스만 고쳤으면 실패한 칸부터 다시 잇는다(소스 다이제스트는 src · public만 센다).
2. **src를 고쳐야 하는 결함이 나오면** — 바로 고치고 칸 1부터 돌지 **않는다.** 기록해 두고 남은 칸을 진단 판으로
   이어 돌아 다 찾은 뒤, 모아 고치고 **같은 소스 1→16 한 번**이 최종이다 (기억 `chain-find-then-final`).
3. 진단 판 병렬(선택) — 옛 세이브로 뒤 칸을 미리 돌릴 수 있다: `.audit/parts/diag/starts/cell-N-start.rpsave`(칸 8~16),
   `node .audit/parts/diag/lane.mjs <이름> <칸…>` 또는 `pnpm part N --save=… --lane=dN --url=…`.
   결과는 `.audit/parts/diag/<lane>/`에 따로 쌓여 연쇄를 안 덮는다. **기계가 붐비면 안 한다**(10-13 세 판 동시는 첫 화면에서
   다 묶였다 — 사용자가 끄라고 했다). 옛 소스의 세이브라 찾은 막힘은 후보일 뿐이다.
4. 연쇄 뒤: `pnpm story` · `gpu:loss` · `render:first` (지금 소스로 안 쟀다 — 빌드가 경고한다).
5. 푸시 → `pnpm build` → 진입 스크립트가 배포본과 같아지면 `pnpm verify:deploy https://radiant.siwon.it.kr/` → e2e 전체(혼자).
   15분 안에 안 뜨면 빈 커밋으로 다시 건다.
6. 릴스 · 새 쇼츠 (`tools/reels`) — 업로드 전략은 보고서 4절.
7. 마지막에 직접 플레이하며 찍어 본다.

## 4. 결정을 기다리는 것

- **WebGL 끊김**: 모래시티 순간이동 한 프레임이 WebGL 9.4~10.8초 · WebGPU 0.47초. 작업트리(`.claude/worktrees/` 아래 ·
  자료는 복사)에서 인스턴싱 · 그림자 패스 줄이기 중 큰 쪽부터. src를 바꾸므로 최종 연쇄 전에 넣을지 사용자에게 묻는다.
- **제품 쪽 작은 틈(후보)**: 걸어서 다리 어귀(0x70)로 올라선 사람이 자전거 널(0x76~0x7d)에 들어서는 것을 제품이 안 막는다.
  원작은 `PlayerAvatar_WillBeOnBikeBridge`(raw/decomp/src/player_move.c)로 막는다. 플래너를 고쳐 길에는 안 나온다 —
  src 수정 묶음에 넣을지 정한다.
