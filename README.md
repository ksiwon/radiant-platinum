# Radiant Platinum

포켓몬스터 플래티넘(NDS)을 **브라우저에서 도는 3D 게임**으로 다시 만든 것.

에뮬레이터가 아니다. 원작 롬에서 자료를 읽어 three.js 위에 새로 세우고, 규칙도
새로 돌린다. 브라우저에서 플래티넘을 *플레이*하는 것은 이미 에뮬레이터로 되므로,
이 프로젝트의 존재 이유는 **3D 리메이크**다.

> **비공식·비제휴 팬 프로젝트다.** 관련 상표와 저작물은 각 권리자의 것이다.
> 이 저장소는 원본 게임 데이터를 **한 바이트도 싣지 않는다** — 자료는 사용자가
> 가진 것에서 각자의 브라우저가 만든다. 남는 위험은 [docs/COPYRIGHT.md](docs/COPYRIGHT.md).

---

## 어떻게 리메이크했나

**타일이 아니라 입체다.** 원작의 맵 조각·충돌면·높이 자료(BDHC)를 그대로 읽어
3D로 세운다. 계단과 턱의 단차, 물 높이, 다리 밑을 지나는 길이 원작의 수 그대로다.
사람·포켓몬·건물 모델은 BDSP 번들에서 굽는다.

**두 화면을 한 화면으로 접었다.** DS 아래 화면에 있던 가방·포켓치·메뉴를 한
화면 배치로 옮겼다. 배치는 지어내지 않고 **BDSP가 같은 문제를 푼 방식**을 따랐다.

**규칙은 롬에서 읽는다.** 종족값·기술·특성·트레이너 편성·조우표·상점 재고·대사·
필드 스크립트를 전부 사용자의 롬에서 뽑는다. 손으로 옮겨 적은 표가 없고, 값의
근거는 디컴파일(`pret/pokeplatinum`)로 맞춘다. 배틀 계산은 `@pkmn/sim`이 돈다.

**끝까지 돈다.** 떡잎마을에서 명예의 전당과 크레딧까지 — 체육관, 사천왕과
챔피언, 깨어진 세계. 진화 스물여섯 갈래, 알과 육성가, 더블 배틀, 파도타기와
낚시, 포켓치, 배틀팩토리가 실제로 걸린다. 체육관 여섯과 리그로 올라가는 길은
계단이 아니라 **움직이는 장치**라, 톱니와 꽃시계와 뜨는 판을 원작의 표 그대로
옮겨야 길이 열렸다. 빠진 것과 그 이유는 [docs/PARITY.md](docs/PARITY.md)에
한 줄씩 적혀 있다.

**세 나라 말이 다 된다.** 영어·한국어·일본어 롬을 지원한다. 번역한 것이 아니라
**각자의 롬에서 그 말을 읽는다.**

**자료는 사용자가 가져온다 (BYOR).** 롬을 고르면 브라우저가 그 자리에서 변환해
OPFS에 설치한다. 서버는 원본도 변환 결과도 받지 않고 저장하지 않는다 —
`connect-src 'self' blob:` CSP가 구조로 막는다.

## 안 하는 것

통신이 있어야 성립하는 것 전부 — 통신 대전·교환·GTS·유니온룸·미스터리기프트.
상대를 세우는 일이라 게임 이식이 아니다. 콘테스트 계통과 지하통로도 접었다.
막아 둔 자리는 원작의 대사로 돌려보낸다. 교환 진화처럼 그 때문에 막힌 길은
**시리즈가 나중에 내놓은 답**(연결의 끈·고운 비늘)으로 도로 연다.

모바일은 범위 밖이다. 노트북 이상이 목표다.

## 돌리는 법

필요한 것: Node 22 · pnpm 9 · 본인이 적법하게 보유한 Platinum `.nds`
(`CPUE` 영어 / `CPUK` 한국어 / `CPUJ` 일본어) · 이미 추출해 둔 BDSP
`AssetAssistant/` 폴더.

`AssetAssistant/`는 BDSP를 풀면 romfs 안 이 자리에 생긴다:

```
romfs/
└─ Data/
   └─ StreamingAssets/
      └─ AssetAssistant/        ← 이것을 고른다
         ├─ Characters/         사람·포켓몬·소품 모델과 동작
         ├─ Pokemon/            종·폼별 모델
         ├─ Environments/       배틀 무대
         └─ …                   (폴더마다 같은 이름의 .bin이 짝으로 있다)
```

`romfs/`·`Data/`·`StreamingAssets/` 중 어느 상위 폴더를 골라도 앱이 아래에서
찾아 내려간다. **푸는 방법은 여기서 설명하지 않는다** — 롬 구하기, 키 얻기,
NSP·NCA 복호화는 이 저장소의 범위 밖이다 ([COPYRIGHT.md](docs/COPYRIGHT.md) §4).

```sh
pnpm install
pnpm dev
```

브라우저가 열리면 롬과 `AssetAssistant/`를 고른다. 첫 설치는 26그룹 7,007개
파일(약 700MB)을 굽고 **5분쯤** 걸린다. 두 번째부터는 변환 없이 바로 뜬다.
